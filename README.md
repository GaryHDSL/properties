# PropertyLink — South African property marketplace

An original, responsive property discovery and lead-generation website concept inspired by the workflow of Moving24, adapted for property buyers, tenants, landlords, sellers and estate agents.

## Included in this first website version

- Responsive landing page and mobile navigation
- Buy, rent and commercial property enquiry form
- Property category cards for residential, rental and commercial spaces
- Customer enquiry journey explanation
- Estate-agent registration interface
- Landlord / seller property submission interface
- Login modal placeholder
- FAQs and calls to action

## Important: prototype status

This repository currently contains a front-end prototype. The forms are intentionally demo-only and do not transmit or save personal information. Login, registration, listing publication, lead routing, notifications, billing and dashboards are not connected to a backend.

The example property cards, prices and photographs are illustrative, not verified available listings. Replace them with approved listings and licensed images before public launch.

## Recommended next development phase

1. Build a secure backend and database.
2. Add verified customer, agent and landlord accounts with password hashing and email verification.
3. Add agent profiles, service-area matching and lead assignment.
4. Add property listing submission, moderation and search filters.
5. Add lead inbox, status tracking, follow-up reminders and notifications.
6. Add admin dashboard, audit logs, privacy controls and consent records.
7. Add payment and subscription features only after pricing and terms are approved.

## Run locally

Open `index.html` in a modern browser. No build step is required for this static prototype.
